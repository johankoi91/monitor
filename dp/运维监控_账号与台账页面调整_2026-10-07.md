# 账号与台账页面调整

日期：2026-10-07。

- 注册表单去除显示名称，只填写账号、密码和确认密码；后端新账号显示名称使用账号名填充，历史账号数据不变。
- 接入密钥保留“直接签发重启安全 Key”，签发结果增加“复制密钥”按钮；用途固定为重启安全 Key，节点范围仍是必填的。
- 容器与基准台账筛选只保留主机 IP 和运行态，运行态只有“运行中”和“已创建”两个选项，默认运行中。
- 容器列表移除资源指标列；启动配置详情响应在页面展示前剔除资源指标，保留启动参数、挂载、端口、网络和生命周期等核对信息。
- 当前基准列表去除 `rtc-pilot`、端口信息和重启禁止状态等摘要字段，仅保留 IP、容器和状态。每行统一使用“设置”按钮，在右侧详情中配置 TCP/业务探测、重启权限或移出台账。
- 新增 `POST /api/v1/baseline/restart-policy`，以基准版本校验方式保存单节点重启权限，仍受独立重启 Key、中心白名单和 Agent 复核约束。

验证：React/Vite 构建、Go race 全量测试、go vet、OpenAPI YAML 校验通过；生产中心已更新，PostgreSQL 账号/台账/Key 数据保留，RTC 与演练服务健康。
