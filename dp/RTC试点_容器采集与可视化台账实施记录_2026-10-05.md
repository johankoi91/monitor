## 本次实现

新增 monitor Go 模块，包含真实 Agent、中心、静态页面、私有配置生成器、systemd 单元和本地 HTTPS 预览。Agent 只读取 Docker Socket，没有重启/停止/删除容器代码；新节点默认禁重启。

实现 Docker 启动配置采集与 Agent 端脱敏，镜像、声明/实际命令、环境、工作目录/用户、挂载、端口、网络及策略可从详情查看。页面跨 Agent 筛选、多选归类、明确增删预览；中心按版本/候选快照校验，生成 YAML、持久提交并立即生效。基准与发现清单分开，过滤、缺失、失联不会自动减少应有节点。
