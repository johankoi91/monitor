改为包公开接口的具名导入 `import { DownOutlined } from '@ant-design/icons'`，保留原账号权限、下拉菜单和退出行为。新增仅绑定回环的模拟账号测试适配器，明确使用模拟数据，无生产身份数据或 Docker 操作；通过 AVOPS_UI_ACCOUNT_FIXTURE=1 启用。

验证先复现旧构建登录后失败，再验证修复版完整登录、账号下拉菜单，以及服务状态、通知、密钥、容器台账、账号权限、操作审计和系统审计页面。TypeScript/Vite 构建、go vet、diff 检查通过。

中心已部署，旧二进制保存在独立 `/var/backups/avops-login-fix.*` 目录。正式页面 http://127.0.0.1:18086 已实际使用 admin 登录，显示 8 个 RTC 节点和演练节点，所有页面可打开、下拉退出成功，浏览器无运行错误。验证未改变业务设置、账号权限或 Key，未执行重启。
