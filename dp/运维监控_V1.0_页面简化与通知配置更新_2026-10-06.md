# V1.0 页面简化与配置更新

日期：2026-10-06。对应用户本次五项调整，源码位于 monitor/frontend、monitor/internal/center/baseline.go 和 monitor/internal/notify/settings.go。

| 调整 | 实现与验证 |
|---|---|
| 通用标题 | 页面与标签页均为“运维监控”；去除 RTC 徽标及 V1.0 · RTC 试点文案 |
| 归属简化 | 表单只保留集群编码与可选端口；中心生成服务归属，已有归属继承，节点精确绑定不变 |
| 主机显示 | 下拉、发现列表、基准成员及节点明细显示 IP，不展示 hostname/Agent ID；内部稳定 ID 与 API 字段保留 |
| 多个 TCP 端口 | 逗号分隔、去重、1–65535、最多 8 个；已纳管成员有独立端口编辑，版本冲突/忙节点拒绝 |
| HTTP/HTTPS 通知配置 | 页面编辑开关、地址、HTTPS 校验域名、可选接收端鉴权；持久保存并立即生效，重启可恢复 |

服务自动归属仅用于生成内部台账，Docker 容器仍以 Agent/精确名绑定。已保存服务名称、重启许可及节点数量不因页面简化而重写；已纳管端口编辑只改 checks。未知容器按稳定名称生成服务编码，前端不再要求选择逻辑服务。

通知配置 GET 不返回密钥，POST 受 Basic Auth、来源和跨站写入控制；版本检查避免覆盖。独立设置文件 notification-settings.json 为 0600。更换地址/TLS 身份不得沿用旧接收端密钥，旧队列停止重试，新事件使用新配置；保存时不能复用管理/Agent 凭证。在途请求被取消，旧响应不复活旧队列，已发往旧目标的请求可能已经被接收，不声称撤回网络数据。

已通过 Go 竞争测试/静态检查、React 类型检查/构建及 OpenAPI 解析/引用验证；新增测试覆盖自动归属/已有归属保持、多端口/重复端口/节点锁、配置跨重启、写入失败/版本冲突、不向新目标转发旧鉴权/旧事件、在途取消。

内置浏览器的独立模拟环境验证：选择一个容器保存 443/8002/8003，后续编辑为 443/8002/8003/4501；表单不出现集群名称/逻辑服务，主机只显示 127.0.0.1；HTTP/HTTPS 地址保存与重新读取通过。模拟验证未改变正式台账或真实通知目标。

正式中心已更新：原 8 个节点，基准版本 6d94ed12eb221a85df179620a7deefaf 保留；原地址 https://114.132.190.201:18443/api/v1/notifications、TLS 身份 edge.rtcdevelopers.com 和接收端鉴权保留，检查时 pending=0、failed=0。未重启业务容器。此次是界面/配置更新，RTM 的实际服务接入仍按后续规划进行。
