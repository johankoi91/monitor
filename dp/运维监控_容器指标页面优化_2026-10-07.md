# 容器指标页面优化

2026-10-07，针对服务节点中指标、时间、说明及重启条件连续堆叠的问题，重新设计 React 容器卡片。更新已部署至中心 111.230.108.76，刷新 [运维监控](http://127.0.0.1:18086) 查看。

- 头部：主机 IP / 检查层级、容器名称、中文状态、观测说明和操作按钮；上报时间可悬停查看完整日期。
- 摘要：CPU、内存工作集、容器文件系统、本次运行时长四个独立数值区，限额及重启次数作为辅助信息。
- 详情：资源、文件系统、生命周期三个页签；资源面板按 CPU、内存、I/O、网络分组，名称与读数左右对齐。
- 文件系统：容量及 inode 独立面板，真实使用率用进度条展示，保留宿主机共享口径。
- 生命周期：创建、上一轮结束、本次启动及最近观测形成时间线，旁边显示运行时长、重启/退出和 Healthcheck。
- 状态说明：共享网络及未取得 I/O 样本作为独立空状态显示；重启白名单及独立 Key/Agent 复核集中在卡片底部。
- 响应式：小于 820px 使用两列摘要、单列详情；小于 520px 头部操作区换行。页签支持方向键和 Home/End，尊重减少动画设置。

非零 CPU 读数低于 0.001 核时显示 `<0.001 核`，避免被显示为精确的零。实际零值、缺失值、未设置限额及过期数据仍分别表达。

TypeScript/Vite 构建通过；浏览器在独立模拟环境验证完整卡片、展开详情、文件系统进度条、生命周期及键盘切换，并检查桌面/窄窗口视觉效果。正式入口已核对新的 JS/CSS 资源及 Agent 在线状态。未新增后端采集或改变重启授权规则。
