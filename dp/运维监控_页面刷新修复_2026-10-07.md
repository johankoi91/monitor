# 页面刷新修复

用户反馈刷新白屏。新浏览器会话可显示登录页，但检查发现原 CSP 的 `style-src 'self'` 拒绝 Ant Design 动态样式：登录按钮退回浏览器默认灰色样式，密码框图标布局失效。此前构建和 API 健康验证不足以证明页面正常。

修复后的 HTML 每次请求生成独立 nonce，由 meta 传入 ConfigProvider，中心 CSP 只允许同源及该 nonce 的样式元素；组件所需内联样式属性单独允许，脚本仍保持 `script-src 'self'`。HTML 不缓存。静态 shell 添加加载提示，React 增加错误边界，脚本未加载或组件渲染失败时保留重新加载入口。Reset 在业务布局样式之前加载。

验证：Go center race 测试检查 HTML/CSP nonce 匹配、刷新 nonce 更新、脚本策略及未认证 API 拒绝；go vet、前端 TypeScript/Vite 构建、diff 检查通过。修复版先在本机 18088 模拟环境验证，再部署到 111.230.108.76，并通过实际 18086 页面重复刷新、注册切换、DOM 与截图确认蓝色 Ant Design 按钮和表单恢复；浏览器记录未发现运行错误。账号与数据使用 pgverify 验证，RTC/演练服务 HEALTHY，没有重启业务容器。

本次浏览器验证覆盖未登录首页和注册页；未在浏览器中执行生产账号权限变更、签发/轮换 Key 或重启任务。旧中心程序已保留在独立 `/var/backups/avops-page-fix.*` 目录。
