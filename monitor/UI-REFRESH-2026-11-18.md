## 改进

首页提供可点击状态汇总、异常优先排序、名称/镜像/IP 搜索、主机与分组筛选、紧凑列表、手机条目布局及按需诊断详情。刷新失败或超过有效时间时保留快照并标记待确认，避免将旧在线状态及资源数值显示成实时结论。

RTC 探针停用增加影响确认；首次读取与空数据区分，创建任务按实际缺失条件提供入口。图表刻度与辅助文字提高对比度，使用不同线型并提供覆盖所有曲线和当前磁盘选择的精确数据表。页面、RTC 子页签、节点、资源页签和筛选状态通过 URL 恢复。

没有调整权限、健康判断、业务确认阈值、重启许可、任务调度或 API 契约。
