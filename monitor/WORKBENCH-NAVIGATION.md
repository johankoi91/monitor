# 监控工作台导航与页面规范

本次实现以已确认的完整工作台原型及两次导航调整为依据。沿用 React / TypeScript / Ant Design / ECharts 和现有 API，不引入新组件库。操作授权、任务调度、保留策略、账号角色及原容器重启协议继续由现有后端执行。

## 信息结构

| 栏目 | 页面 |
| --- | --- |
| 运行总览 | 分开查看纳管容器、容器检查、RTC 业务和通知投递统计 |
| 监控 | 容器服务；资源、启动参数、文件系统、生命周期保留在具体容器详情内 |
| RTC 业务探测 | 探测任务、目标服务、探针、执行记录、历史与容量 |
| 容器台账 | 未纳管发现、当前基准；共用待保存变更与保存确认流程 |
| 通知投递 | 投递记录、接收配置；事件类型和结果作为筛选 |
| 运维 | 操作与审计（使用者为我的重启）、中心容量（沿用 monitor.read 读取权限） |
| 管理 | 重启 Token、账号管理、角色说明；固定角色说明只读 |

栏目独立展开、收起；收起不改变当前页面，父级保留选中提示。创建、编辑、重启、签发和停用继续作为页面动作。侧栏和内容均按既有权限控制，URL 不赋予额外权限。

## 位置与状态

页面使用 `view` 和 `page` 查询参数，例如 `?view=rtc&page=targets`、`?view=inventory&page=baseline`、`?view=notifications&page=config`。兼容原 `view=status/rtc/inventory/notifications/operations/access/accounts` 入口。刷新及前进后退恢复对应页面；未授权或无效入口回到有权限的页面。普通链接支持另开标签页。

`node` 定位容器详情，`range` 记录资源趋势时间范围。台账多选、待保存新增、移出草稿和分组设置由共同父组件保存，跨子页面与其他模块切换不丢弃。表单凭证不写入 URL 或导航存储；展开偏好仅记录栏目开关。

## 样式与反馈

系统中文字体、蓝色选中态、浅色背景、紧凑表格、清晰的状态文字。桌面侧栏 204px；窄屏提供可展开的导航入口，选择子页面后自动收起并聚焦页面标题；宽数据表在自身容器内滚动。采用原生链接和按钮，展开按钮暴露 `aria-expanded` / `aria-controls`，当前页面使用 `aria-current=page`，保留可见键盘焦点与系统减少动效偏好。

首次加载使用骨架屏，读取失败提供重试。临时反馈在切换页面或短暂展示后清除。容器运行和探针在线不当作 RTC 业务正常。发送端的接收指标明确标为不适用；RTC 最近轮次缓存与持久历史分别标示。数据库提示阈值用于提醒，进度展示真实数据盘使用率。
