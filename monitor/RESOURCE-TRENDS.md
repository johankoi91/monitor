# 容器资源趋势

服务状态 → 查看详情 → 资源详情提供 CPU、内存、磁盘 I/O、网络四张时间曲线。支持最近15分钟、1小时、6小时、24小时，页面每15秒更新。CPU单位为逻辑核；内存展示工作集、RSS、总使用；磁盘可切换读写速率/IOPS和具体设备，不重复累加逻辑盘与底层设备。

中心从现有Agent上报的cAdvisor指标中提取数值，按30秒时间桶保存最新实际采样至 PostgreSQL `avops.resource_samples`。历史保留7天，中心启动及每小时清理过期记录；6小时/24小时查询分别按2分钟/5分钟选取最新实际采样。不另加采集器，启动参数改为Agent主动上报，最后有效记录单独加密持久化，不写入资源历史表，详见STARTUP-REPORTS.md。

只记录当前基准成员；查询沿用monitor.read权限，只允许查询当前基准节点。容器ID和启动时间用于标记运行实例变化，断网、采样缺失、重启或重建时断开曲线，空值不补0。host/container共享网络没有单容器流量曲线；磁盘指标不可用时保留空缺。已移除“更多当前指标”，文件系统和生命周期表格保留。

历史自部署时开始积累，不伪造或补写部署前数据。正式环境需要新增历史表及运行账号的SELECT/INSERT/UPDATE/DELETE权限；新建环境由数据库迁移自动创建。file-dev及隔离演示模式使用受限内存历史，不能替代生产持久化。
