# V1.0.4 改动汇总（2026-11-02）

本版为V1.0的交互、鉴权、通知和指标完善，服务端API版本仍为v1。完整部署过程见OPTIMIZATIONS-2026-11-02.md；以下按最终行为汇总，不沿用过程中已取消的设计。

| 范围 | 本版最终行为 |
| --- | --- |
| 账号 | 两类角色显示为管理者/使用者，原权限不变；同账号新登录撤销旧会话 |
| REST重启 | 使用单个有到期时间的Bearer Token，自动归属当前账号，支持撤销；不再使用Key ID/Secret对或节点范围选择；仍须通过双端白名单、现场容器ID、配置指纹、互斥和冷却检查 |
| 容器发现 | 仅展示未纳管且Agent在线、数据未过期的可选容器；保留运行中/已创建/已停止/暂停/重启中筛选，去掉删除中/故障选项；同名重建不会丢失纳管关系 |
| 台账交互 | 使用分组名，可选已有分组或输入中文名；左侧发现/当前基准，右侧固定待保存变更和保存入口，支持跨页勾选 |
| 服务状态 | 分组→主机IP→容器二级归类；仅主机IP/分组筛选；移除全局刷新和分组正常标签；异常/未知正数标红；摘要改为CPU、内存、数据更新时间、运行时长 |
| 资源趋势 | CPU、内存、磁盘I/O、网络四张时间曲线，15分钟/1小时/6小时/24小时，设备与IOPS切换；PG保留7天历史，缺失与重启处断线、不补0；移除更多当前指标，保留文件系统/生命周期表格 |
| 启动参数 | Agent主动上报原值，页面显示最新上报时间；PG加密保存最后有效记录，停止/删除/离线仍能查看，旧容器ID和历史状态明确提示；不再WSS按需获取 |
| 通知 | 按接收地址添加配置、选择事件，独立签名/启停/测试/删除；支持正常、容器异常、采集异常、恢复四类；正常首次同步、后续仅变化通知，去重状态可恢复；只发节点通知 |
| 交付 | 五类服务镜像齐备，Web嵌入中心；包括安装、迁移、源码、镜像ID和SHA256；新环境隔离安装验证包含真实cAdvisor、接收端和完整Token重启链路 |

节点对外以IP-容器名定位，内部继续保留稳定Agent ID与容器名；分组名为展示归属。共享网络不归属单容器，I/O未知与真实0明确区分。账号、台账、操作和通知配置不因升级而清空。试点中已按用户要求清空旧签发Token，本包不携带或恢复凭证。

文档当前整理为1.0/与1.1/目录；V1.1规划不算本版已实现功能。原型截图是文档资料，最新实际页面以本版嵌入Web为准。

升级需先备份数据库及独立存储密钥，owner执行数据库迁移，再更新中心/Agent；REST调用方改用新签发Token。正式DNS、客户来源白名单、长期/最大规模压测和现场业务批准仍需按交付条件完成，本次隔离验收不能替代这些结论。

本版全量Go竞争测试、隔离PostgreSQL集成测试及Chrome页面检查通过。全服务离线包已在全新PG数据目录完成干净安装，覆盖cAdvisor真实采样、接收端签名与去重、参数缓存、历史恢复和独立canary的Token REST重启；原始步骤结果见 ../releases/monitor-1.0.4-clean-install-proof.json。
