# 后续 UI 概念稿

该目录保留早期可视化设计，仅作为客户自定义 UI 或后续独立 UI 项目的参考，不属于 V1.0 交付范围。页面不连接真实服务器，不执行真实容器重启。

直接通过本地 HTTP 服务打开：

```bash
cd deploy_console/product_prototype
python3 -m http.server 18082
```

主要流程：

1. 在运行总览查看 RTC、RTM 聚合状态。
2. 在服务监控中按产品、状态和关键字筛选。
3. 点击服务或节点打开详情侧栏。
4. 对允许操作的运行中节点发起模拟重启。
5. 在运维操作中观察执行状态和结果。
6. 在服务基线中查看应有节点配置。
